# Diet Plan & Tracker — Store Review Instructions

## App Store (iOS) Review Notes

### Reviewer Account
- **Username:** `review`
- **Password:** `Review@2026!`
- The review account has pre-generated meal plan data for testing.

### Features to Review
1. **Sign Up** — Create a new account with username + password
2. **Log In** — Use the review account or your own
3. **Google Sign-In** — Available if configured (not enabled by default in review builds)
4. **Onboarding** — First-time users go through goal setting, then generate an AI meal plan
5. **Meal Plan Review** — After generation, review and confirm your personalized meal plan
6. **Meal Tracking** — Log meals from the Meals tab, mark as eaten
7. **Food Search** — Search for foods in the tracker; camera barcode scanning available
8. **Water Tracking** — Log water intake in the Tracker tab
9. **Weight Tracking** — Log weight entries in the Tracker tab
10. **Shopping List** — Auto-generated from meal plan, with check-off capability
11. **Account Deletion** — Profile → Delete Account (requires password re-entry)
12. **Reset Password** — Login screen → Forgot Password? (requires SMTP configured for email delivery)
13. **Privacy Policy** — Accessible from login screen and Profile tab
14. **Terms of Service** — Accessible from login screen and Profile tab
15. **Analytics Toggle** — Profile tab → Usage Analytics toggle

### AI Features
- Meal plans are generated by AI (OpenAI / Anthropic) based on user profile data
- AI disclosure is shown on the plan review screen and Profile tab
- Medical disclaimer is shown on the login screen and Profile tab
- Single meal regeneration: tap ↻ CHANGE on any meal to get AI alternatives

### Permissions Used
- **Camera** — Barcode scanning for food lookup (justified in Info.plist)
- **Photo Library** — Attach meal photos (justified in Info.plist)
- **Notifications** — Meal reminders (configured but not actively used in v1.0)

### Data Safety
- All API communication uses HTTPS/TLS 1.3
- Passwords hashed with bcrypt (12 rounds)
- JWT tokens in httpOnly cookies + sessionStorage fallback
- Analytics opt-in required; no PII sent to analytics
- Account deletion permanently removes all data within 30 days

### Notes for Apple Reviewer
- This is v1.0 of the app. Some features (Apple Sign-In, push notifications) are scaffolded but fully functional.
- The app uses Capacitor (hybrid native/web) — no embedded content or third-party advertising.
- No in-app purchases or subscriptions in this version.
- No HealthKit integration.
- ITSAppUsesNonExemptEncryption = false (no custom encryption).

## Google Play Store Review Notes

### Reviewer Account
- **Username:** `review`
- **Password:** `Review@2026!`

### Data Safety Declaration
The following data is collected:
- **Personal info** (name, email, username) — for account management
- **Health & fitness** (weight, height, dietary preferences, allergies, goals) — for meal plan generation
- **App activity** (meal logs, feature usage) — for core functionality
- **App diagnostics** (crash data, performance) — for app improvement

Data is **not shared** with third parties except:
- AI providers (OpenAI/Anthropic) — for meal plan generation only; not used for training
- PostHog — anonymized analytics (opt-in)

### Permissions
- `INTERNET` — API communication
- `ACCESS_NETWORK_STATE` — Connectivity monitoring
- `CAMERA` — Barcode scanning for food lookup
- `READ_MEDIA_IMAGES` — Attach meal photos (Android 13+)
- `POST_NOTIFICATIONS` — Meal reminders (Android 13+)

### Account Deletion
Available in-app: Profile → scroll to bottom → Delete Account.
Requires password re-entry for security. All data permanently deleted within 30 days.

### Note for Play Store Reviewer
- Version 1.0 — initial release
- No ads
- No in-app purchases
- No subscription required
- AI-generated content is clearly disclosed
- Medical disclaimer present on login and profile screens
